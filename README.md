# Extract-Question
Đây là Code được tạo ra để trích xuất câu hỏi ôn tập từ trang web "https://elearning.utt.edu.vn/" của đại học công nghệ giao thông vận tải (UTT).

Các bước thực hiện:
B1: Tải Extractor.exe trong phần <a href="https://github.com/WaterKansuza/Extract-Question/releases/tag/Update">release </a> <-- Nhấn vào đây hoặc nhấn như mũi tên bên dưới
<img width="1875" height="539" alt="Tutorial" src="https://github.com/user-attachments/assets/2008bd7a-ab6a-439b-8289-5218108c11f8" />

B2: Bắt buộc phải làm xong một bài và phải được hiển thị như ảnh bên dưới
<img width="1865" height="874" alt="Ví dụ 1" src="https://github.com/user-attachments/assets/aaeac148-1627-4486-ad54-b1a5fdad3c8c" />

B3: Nhấn F12 và làm như bên dưới ( Tìm Sources -> tìm view.php trong thư mục "top/.mod/quiz/." -> Chuột phải -> Save as... )
<img width="1048" height="733" alt="Bước" src="https://github.com/user-attachments/assets/edc7eb42-d9ec-48ac-9fdc-d5849dd50a3b" />

<b>*Lưu ý:</b> PHẢI cho "review.php" ở cùng thư mục với "Extractor.exe"

B4: Nhấn đúp chuột vào "Extractor.exe"
B5: Đợi giây lát và file docx sẽ được gửi về tên là "output.docx"
